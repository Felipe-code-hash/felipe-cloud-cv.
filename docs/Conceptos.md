## Frontend

Es la parte de una aplicación con la que interactúa el usuario. Incluye la interfaz gráfica, los botones, el texto, las imágenes y todo lo que se muestra en el navegador. Normalmente está desarrollado con HTML, CSS y JavaScript.

## Backend

Es la parte de una aplicación que trabaja detrás de escena. Se encarga de procesar la lógica del sistema, validar usuarios, comunicarse con bases de datos, ejecutar reglas del negocio y responder a las solicitudes del frontend.

## API (Application Programming Interface)

Es un mecanismo que permite que dos aplicaciones se comuniquen entre sí. Actúa como intermediario entre el frontend y el backend, recibiendo solicitudes, enviándolas al servicio correspondiente y devolviendo una respuesta.

## NAT (Network Address Translation)

Es un mecanismo que traduce direcciones IP privadas a una dirección IP pública para permitir que recursos dentro de una red privada accedan a Internet sin exponer directamente sus direcciones privadas. En AWS, esta función la realiza normalmente un NAT Gateway.

## HTTP

Es un protocolo que define cómo un cliente y un servidor intercambian información mediante solicitudes (requests) y respuestas (responses).

## HTTPS

Es la versión segura de HTTP. Utiliza cifrado mediante TLS para proteger la información durante su transmisión entre el cliente y el servidor.
