CV en la nube

Desarrollo y despliegue de un currículum web utilizando servicios de Amazon Web Services. El proyecto implementa una arquitectura basada en Amazon S3 y CloudFront para la distribución del sitio, junto con API Gateway, Lambda y DynamoDB para el contador de visitas.

También se implementaron mecanismos de seguridad, monitoreo y control de tráfico mediante IAM, CloudWatch, SNS, Shield Standard, CORS, throttling y políticas de encabezados de seguridad.
